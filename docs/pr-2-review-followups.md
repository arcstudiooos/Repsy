# PR #2 review — Minor findings and follow-ups

Every Minor finding from the PR [arcstudiooos/GYM#2](https://github.com/arcstudiooos/GYM/pull/2) review (`docs/pr-2-review/review-*.md`, `rereview-F1.md`), with what happened to it.
